What Statute Watch is for

US state privacy law is a moving target. Every session, states introduce, amend, pass, and bring into force bills touching location tracking, biometric identifiers, data-broker registration, and comprehensive consumer-privacy rights. The signal that matters to a privacy or compliance team, which state just changed which obligation, is scattered across fifty legislatures and buried in statutory language few people have time to read.

Statute Watch collects those changes into one browsable dossier. Each entry records the state, the bill number, the data types it governs, where it sits in its lifecycle (introduced, passed, enacted, or in effect), and a short plain-English note on what the law actually requires. You filter by state and data type to see exactly the slice you own, instead of keeping fifty bill trackers open in browser tabs.

How to use it

Pick a state to see everything tracked there, or a data type (say biometric or data-broker) to compare how states treat the same category. The stage filter separates laws already in effect from bills still moving, so you can tell a live compliance obligation from one worth watching. Every card links straight to the official bill record, because the dataset only tracks a state once an authoritative legislative source is registered for it. The whole thing is a static site and an open dataset: nothing to log into, and you can host or fork your own copy from the repository.

Frequently asked questions

Which privacy laws does Statute Watch track?
US state statutes covering geolocation, biometric data, data brokers, comprehensive consumer privacy, health data, and children’s data. Federal law and non-privacy statutes are out of scope.
How current is the data?
The dataset is curated from official legislative records and refreshed on a schedule. It is a reference, not a real-time alert feed, so confirm any bill against the linked official source before you act on it.
Is this legal advice?
No. Statute Watch is an informational tracker for research and monitoring. It does not interpret how a law applies to your organization.
Where does the data come from?
Every tracked state is backed by a registered official source (its legislature’s own record). A state with no registered source is rejected by the build, so nothing ships without provenance.
Can I use the dataset in my own tools?
Yes. The project is MIT licensed and the data ships as plain YAML plus a data.json built alongside this page, so you can query or import it directly.
